# Hyprland Rice

Мой hyprland rice для **Arch Linux** и **Fedora 44**.
В репозитории собраны панель, меню приложений, уведомления, экран блокировки,
обои и настройки Hyprland. Установщик задаёт вопросы и собирает конфигурацию
под твой компьютер.

## Для каких систем

| Система | Какой установщик использовать |
| --- | --- |
| Arch Linux | `install.sh` — пакеты через pacman и AUR |
| Fedora 44 с DNF5, обычная установка | `install-fedora.sh` — пакеты через DNF5 |
| Fedora Atomic: Silverblue, Kinoite и другие варианты на rpm-ostree | Эти установщики не поддерживают такую установку |
| Другие дистрибутивы и версии Fedora | Поддержка не заявлена; скрипты проверяют систему перед установкой |

Значок батареи можно отключить. Нужны установленные графические
драйверы с поддержкой Wayland, интернет, Git и доступ к `sudo`.

## Что входит в rice
| Компонент | Для чего нужен |
| --- | --- |
| Hyprland | Управление окнами, рабочими столами и сочетаниями клавиш |
| Waybar | Верхняя панель: рабочие столы, часы, звук, обновления и батарея |
| Quickshell | Меню приложений, выбор обоев, календарь и профили питания |
| SwayNC | Уведомления и боковая панель быстрых действий |
| Hyprlock | Экран блокировки |
| Kitty / Thunar / Rofi | Терминал, файловый менеджер и дополнительное меню запуска |
| Flat Remix | Светлая и тёмная темы оформления и иконки |
| Bibata Modern Ice | Курсор мыши, если согласиться на замену |
| awww / swww | Показ и смена обоев |

В лаунчере есть переключатель светлой и тёмной темы. Календарь открывается
при наведении на часы, а нажатие на батарею — меню профилей питания.
Набор доступных профилей зависит от оборудования.

## Как установить

Открой терминал **от обычного пользователя**. Не запускай скрипт через
`sudo bash`: он сам запросит пароль, когда понадобятся права администратора.

Сначала скачай репозиторий и перейди в его каталог:

```bash
git clone https://github.com/shingetsu5/arch-hyprland-ricing.git
cd arch-hyprland-ricing
```

Для установки запусти подходящий скрипт:

```bash
# Arch Linux
bash install.sh

# Fedora 44
bash install-fedora.sh
```

**Выбери одну команду для своей системы.** Введи номера нужных вариантов.
Нажатие Enter с пустым вводом оставляет выделенный вариант по умолчанию.

Затем скрипт установит пакеты, подготовит и проверит конфиги, сохранит старые
настройки и перенесёт новые. В Arch этот этап также выполняет полное
обновление системы через `pacman -Syu`. Для пакетов AUR используется yay;
при его отсутствии установщик соберёт его из AUR.

После завершения можно согласиться на перезагрузку. На экране входа выбери
сессию **Hyprland**. Если выбрана установка SDDM, новый экран входа начнёт
использоваться после перезагрузки.

### Особенность Fedora

Для части компонентов Hyprland нужен дополнительный источник пакетов.
Установщик предлагает подключить **COPR `sdegler/hyprland`**. COPR — это
сервис дополнительных репозиториев, которые поддерживают их авторы.

На чистой Fedora 44 выбери подключение этого источника. Если нужные пакеты
уже доступны из настроенных репозиториев, его можно пропустить. При нехватке
пакетов скрипт остановится до замены конфигов.

Темы Flat Remix, шрифт значков и выбранный курсор Bibata загружаются из
проектов их разработчиков. Версии и контрольные суммы закреплены в
[`installer/assets.json`](installer/assets.json); полученные архивы проверяются
перед распаковкой.

## Что можно выбрать

| Вопрос | Варианты |
| --- | --- |
| Показывать батарею в панели? | Да / нет |
| Какое разрешение использовать? | Автоматически; 1080p — 1920×1080; 1440p / 2K — 2560×1440; 3K — 3072×1920; 4K — 3840×2160 |
| Какая частота обновления? | 60, 75, 90, 120, 144, 165 или 240 Гц |
| Какой масштаб интерфейса? | 100%, 150% или 200% |
| Добавить обои из репозитория? | Скопировать / оставить свои |
| Заменить курсор? | Bibata Modern Ice / сохранить текущий |
| Установить SDDM? | Установить и выбрать его / сохранить текущий экран входа |
| Установить Zsh и Oh My Zsh? | Установить и сделать Zsh основной оболочкой / пропустить |

Для каждого найденного монитора вопросы задаются отдельно. Если экраны
определить не удалось, выбранные параметры станут общим правилом.

При автоматическом разрешении используется рекомендуемый монитором режим,
включая частоту. Масштаб по умолчанию: 100%, для 4K — 150%, для 3K — 200%.

При отказе от обоев сохраняется выбранное изображение и его каталог, если
они найдены. При копировании одноимённые изображения не перезаписываются.
При выборе Oh My Zsh установщик делает Zsh основной оболочкой пользователя,
в том числе если Oh My Zsh уже установлен. Изменение вступает в силу после
выхода из учётной записи и повторного входа. Zsh использует `~/.zshrc`;
существующие `.zshrc` и `.bashrc` сохраняются. Если пропустить установку
Oh My Zsh, основная оболочка останется прежней.

## Где находятся настройки

После установки основные файлы лежат в домашнем каталоге:

| Путь | Что настраивает |
| --- | --- |
| `~/.config/hypr/hyprland.conf` | Окна, клавиши и запуск компонентов |
| `~/.config/hypr/monitors.conf` | Разрешение, частоту и масштаб экранов |
| `~/.config/waybar/` | Панель и её модули |
| `~/.config/quickshell/` | Лаунчер, календарь и меню питания |
| `~/.config/swaync/` | Уведомления и быстрые действия |
| `~/.config/appearance/preferences.json` | Выбор обоев и замены курсора |
| `~/Pictures/wallpapers/` | Обои, добавленные из репозитория |

Waybar проверяет обновления через pacman/yay на Arch и DNF5 на Fedora.
Нажатие на значок обновлений открывает список; установка обновлений запускается
в терминале с обычными подтверждениями пакетного менеджера.

## Резервные копии и возврат настроек

Перед заменой прежние конфиги сохраняются в:

```text
~/.local/state/arch-hyprland-ricing/backups/<дата-время-pid>/
```

Журналы установки находятся рядом, в каталоге `logs/`. Если задана переменная
`XDG_STATE_HOME`, вместо `~/.local/state` используется указанный в ней путь.

Чтобы вернуть прежние настройки, выйди из Hyprland, открой папку нужной
резервной копии и верни сохранённые каталоги из `.config/` на прежние места
в `~/.config/`. Новые версии этих каталогов сначала перемести в отдельную
папку, чтобы сохранить возможность вернуться к rice. В копии также есть
описание выбранных параметров и список добавленных файлов.

При ошибке самого копирования скрипт восстанавливает заменённые конфиги
автоматически. Установленные пакеты и изменения системных служб при этом
не откатываются. Если установка остановилась, путь к журналу будет показан
в терминале.

## Как удалить rice

Для Arch и Fedora используется один скрипт.

Для удаления **выйди из графической сессии**, нажми `Ctrl+Alt+F3`, войди
под своим обычным пользователем и открой каталог репозитория. Затем запусти:

```bash
bash uninstall.sh
```

Не запускай его через `sudo`: необходимые права скрипт запросит сам.
В цветном меню выбери, до какой установки вернуть настройки. По умолчанию
выбрана самая ранняя найденная установка — будут отменены она и все последующие.
Затем выбери, удалять ли добавленные пакеты. По умолчанию пакеты сохраняются.
Перед началом скрипт покажет список действий и попросит подтверждение.

Для **новых установок**, выполненных установщиками из этой версии репозитория,
скрипт:

- возвращает прежние конфиги; каталоги rice, которых раньше не было, убирает;
- убирает добавленные обои, ASCII, локальные темы, курсор и шрифт;
- возвращает прежнюю оболочку, GTK-настройки и состояние автозапуска служб,
  включая прежний экран входа; изменения, сделанные позже вручную, сохраняет,
  если их можно отличить от настроек rice;
- убирает Oh My Zsh, если его добавил rice, и восстанавливает прежний файл COPR
  либо удаляет добавленный; изменённый позже файл COPR сохраняется;
- по отдельному выбору удаляет пакеты, появившиеся при установке rice.
  Ранее установленные программы, пакеты обновления Arch и программы,
  установленные отдельно позднее, не включаются в список удаления.

Обновление Arch не откатывается: старые версии пакетов не возвращаются.
Если удаляемые пакеты нужны другим программам, пакетный менеджер остановит
удаление. На Fedora перед DNF выполняется проверка зависимостей точного списка
через RPM; остальные имена пакетов дополнительно защищаются от удаления.
Рекурсивное удаление зависимостей и автоматическое подтверждение не используются.
Если хочешь оставить добавленные программы, ответь «Нет» на вопрос о пакетах.

Текущие конфиги и даже изменённые после установки файлы не пропадают:
они перемещаются в архив:

```text
~/.local/state/arch-hyprland-ricing/removed/<дата-время-pid>/
```

Исходные резервные копии, журнал установки и сам репозиторий сохраняются.
Данные о новой установке находятся рядом в `installations/`.
Если системный этап или удаление пакетов прервётся, повтори запуск и выбери
ту же исходную установку: уже восстановленные файлы повторно заменяться не будут.
